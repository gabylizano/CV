# AGENTS.md

This repository currently contains a professional CV in Markdown format. Below are guidelines for any future development work.

The main.md file contains all the information related to Gabriela's experience, education, and whatever is need for job applcation.

Project idea is tailor resumes using the main.md information and generate a new one.

## General rules

- never modify main.md

## File Structure

- main.cv file with all the information
- tailored/<job_application>.md

## Rules to write tailored resumes

- Markdown
- Emphasize achievements
- Change or add only specific words to match the job role, but do not mofify the whole paragraph
- No more than 2 achievements per role, match the more relevant for the job role position
- Don't add a key achievements section
- Write achievement to each previous position but don't add a subtitle like "key achievements"
- ATS-Friendly
- My title is "Senior Project & Program Manager"
- Never modify the ¨Professional Profile" section"
- Don't use repeatitive language or words when modifying job descriptions or achievements
- Remove all --- horizontal rule separators from markdown
- Maximum 2 bullet points per job/company experience
- Minimum 5 lines per bullet point

## Formatting for Final Output

- Font: Carlito
- Font size: 11
- Margins: 0.5 inches (top, bottom, left, right)
- Text alignment: Justified
- Center Name and Job Title
- No bullets or labels - keep only values (email, phone, location, LinkedIn, GitHub)
